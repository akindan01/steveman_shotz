

A modern and responsive portfolio website for SteveMan, a professional photographer based in Lagos, Nigeria. This platform showcases high-end portraits, editorial fashion, breathtaking travel stories, and commercial videography services, designed to capture the raw, unfiltered essence of human emotion and the beauty of the world.

## Features

*   **Dynamic Hero Section**: Engaging introduction to SteveMan's work and services.
*   **Comprehensive Services Overview**: Detailed sections for Portrait Photography, Editorial & Travel, and Commercial Videography.
*   **"About Me" Section**: Personal story of the artist behind the lens, highlighting experience and philosophy.
*   **Interactive Portfolio Gallery**: A curated display of selected works with an option to "Explore All" for a full view.
*   **Transparent Process Breakdown**: Clearly outlines the "Discovery," "Session," "Retouching," and "Delivery" steps.
*   **Client Testimonials**: Authentic feedback from satisfied clients.
*   **Integrated Contact Options**: Easy access to direct booking via WhatsApp and email for collaborations.
*   **Social Media Connectivity**: Links to Instagram and Twitter profiles.
*   **Responsive Design**: Optimized for seamless viewing across all devices.
*   **Smooth Animations**: Enhanced user experience with elegant transitions powered by Framer Motion.

##  Technologies Used

*   **React**: A JavaScript library for building user interfaces.
*   **Framer Motion**: A production-ready motion library for React.
*   **Tailwind CSS**: A utility-first CSS framework for rapidly building custom designs.
*   **Lucide React**: A collection of beautiful and customizable open-source icons.
